# Evidence records

Add one record per researched lesson using `docs/templates/research-record.md`. Name it `<stable-lesson-id>.md`. Store source claims, dates, evidence types, access restrictions, conflicts, and actual experiment references here.

The initial course reorganizes the existing 14 November 2026 research kit. Its original citations remain in the lesson readings and long-form resources. No new per-source review records or hands-on model comparison results are invented by this import. Before a future update is called current, check its primary sources and create the corresponding record.

Source records are editorial files, not automatically published lessons. Do not place private credentials, private learner data, or copyrighted full articles in this folder.
