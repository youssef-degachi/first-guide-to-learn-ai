## The idea

Generation and controlled editing test different abilities. An edit has two jobs: make the requested change and preserve the rest. Compare against the original rather than relying on memory.

### Name the change and the invariants

Ask to change only the notebook color. Explicitly preserve the headline, layout, other objects, framing, and supporting colors. Use the original through the tool's supported reference or editing mechanism.

### Score both sides

Record whether the notebook changed correctly. Then inspect preservation separately. A successful color change with damaged text is a mixed or failed result under this brief.

### Revise precisely

Name the observed defect and request the smallest correction. If the tool cannot preserve the required element, use an editor or a different workflow and record that extra effort. See the [media briefs](downloads/learning-kit/practice-inputs/media-briefs.md).

## Try it

**Time/access:** 20–40 minutes; Media editing.

Edit the Lab 23 result: change only the notebook to green. Use the original as a reference through the tool's supported editing method.

**Check:** Compare headline, layout, objects, colors, and framing against the original. Score the requested change separately from preservation of everything else.

**Save/teach:** A side-by-side comparison with visible unintended changes, if any. “The edit worked” needs more evidence than the changed notebook.

## Check your work

Compare the original and edit side by side. Check text and unrelated objects at full resolution.
